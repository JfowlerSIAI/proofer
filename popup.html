Correct as you type

Proofreads each sentence as you finish it, using the text before it for context. English multiline text boxes, plus the rich editors the write has been measured against: Slate, ProseMirror, Quill, Lexical, Draft and Trix. Anywhere else it refuses, and says so below.

Proofer is not correcting anything yet.

Turn it on and, as you finish each sentence, Proofer writes its correction straight into the field and flashes the changed words green. Escape takes a correction back, and Recent changes below lists what it did. It works on every site except ones you switch off, and runs on your computer — nothing you type is sent anywhere.

It also keeps a log on this computer of the sentences it checks, so its work can be reviewed — see Recording below.

Recent changes

Recent Proofer writes that changed a text field, newest first. Each receipt explains what the editor did; a misplaced write shows the proposed replacement. Corrections refused by a guard are not shown.

Recording

Proofer keeps a log on this computer of the sentences it checks — including ones it didn't change — up to 400 characters of the text before each, the site, what Proofer proposed (including corrections it chose not to make), and any edits you make to its corrections. Nothing is sent anywhere. Export saves it as a file you can choose to send; Clear deletes it from this computer (files you already exported are yours and are not touched).
